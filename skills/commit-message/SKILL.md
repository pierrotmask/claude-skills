# コミットメッセージの書き方

コミットメッセージは、必ず次の形式で日本語で書く。

## 形式

```
<種類>: <要約>

- <変更点1>
- <変更点2>
```

## 種類（1つだけ選ぶ）

| 種類 | 使う場面 |
|---|---|
| 追加 | 新しい機能やファイルを加えた |
| 修正 | バグや誤りを直した |
| 変更 | 既存の動きや見た目を変えた |
| 削除 | 機能やファイルを取り除いた |
| 文書 | README やコメントなど、説明だけを変えた |

## ルール

- 要約は 30 文字以内で、「〜する」ではなく「〜を追加」のように体言止めにする
- 変更点は箇条書きで、何を・なぜ変えたかを書く（3 個まで）
- 変更が 1 つだけで要約で十分なら、変更点は省略してよい
- コミットする前に `git diff --staged` で実際の変更内容を確認してから書く

## 例

```
追加: ログイン画面を作成

- メールアドレスとパスワードの入力欄を用意
- 入力が空のときはボタンを押せないようにした
```

```
修正: README の誤字を訂正
```
