# Visual & UX Principles

UIやビジュアル要素を設計・実装する際は、レイアウト構成・配色・タイポグラフィの創造的判断を `frontend-design` に委ねつつ、以下の人間工学的原則と情報設計をすべての画面に適用すること。

## 1. 視線の優先順位と空間設計（Information Hierarchy）
- **主役の明確化**: アプリの核となる領域（3Dビューポート、グラフ、主要な計算結果、操作対象など）が画面を開いた瞬間に最も自然と目に入る構成にする。設定項目や補助コントロールは主役を圧迫せず、必要なときにすぐアクセスできる位置に整理する。
- **余白によるグルーピング**: 枠線や装飾を過剰に増やすのではなく、余白（スペース）とコントラストの緩急によって情報のまとまりと優先度を表現する。

## 2. マルチデバイス操作性（Ergonomics）
- **片手操作と精密操作の両立**: スマートフォンの縦持ち片手操作でも親指で無理なくタップ・操作できる快適さと、PCの広い画面で一覧性・精密操作性を発揮するレイアウトを両立させる。
- **モバイル入力のストレス排除**: 数値入力ではモバイル端末で適切なキーパッドが立ち上がるようにし、入力欄へのフォーカス時に画面が意図せず自動ズームされるストレスを防ぐ。
- **誤操作の防止**: 破壊的な操作（リセット・削除）と主要な実行操作は、視覚的な重みと配置を明確に分け、誤タップを誘発しない距離感を保つ。

## 3. 数値・データの視認性（Quantitative Clarity）
- **数値と単位の分離**: 寸法・計測値・計算結果などの重要な数値は最も視認性の高いサイズ・ウェイトで際立たせ、単位やラベルは主役の数値を邪魔しない控えめな表現で明確に区別する。
- **動的変化時の安定性**: スライダー操作やリアルタイム計算で数値が連続的に変化する際も、桁数の増減によって周囲のレイアウトがガタついたり横揺れしたりしないよう文字幅の安定性を保つ。

## 4. インタラクションとフィードバック（Responsiveness）
- **アプリ内で完結する対話**: 操作完了、コピー、入力エラー、確認ダイアログなどのフィードバックは、ブラウザ標準のポップアップ（`alert` / `confirm` 等）を一切使わず、アプリのデザイン言語に溶け込んだトースト通知やインライン表示で即座に返す。
- **状態の可視化**: 選択中のモード、アクティブな要素、ホバー・フォーカス・処理中の状態が、説明文を読まなくても視覚的な変化だけで直感的に判別できるようにする。

## 5. 日本語UIの洗練（Japanese Typography）
- **自然で簡潔な語彙**: ラベル、単位、ガイド文は利用者が直感的に理解できる自然な日本語で統一し、不要な英語の専門用語や直訳調の表現を避ける。
- **改行と文字組みの配慮**: 狭い画面幅でもボタンや見出しの日本語が不自然な位置で折り返されないよう、文言の長さと余白のバランスを整える。
